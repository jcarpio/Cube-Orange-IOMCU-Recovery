# Firmware binaries — not supplied

The `.px4` firmware files from Builds A/B/C are **not bundled** in this documentation-only package. To provide Build C, copy the exact `.px4` produced by the Builder, verify its metadata and record its SHA-256. Publish it only as explicitly experimental and not validated for any actuator, aircraft or mower use. Do not replace it with a similarly named binary lacking provenance.
